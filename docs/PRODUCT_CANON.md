# Ascendant Product Canon

## Product
Ascendant is a premium, cross-device real-life RPG. Real-world actions drive quests, battles, story, loot, stats, companions, and ship/world progression. It must feel like a game first, never a productivity dashboard wearing RPG cosmetics.

## Locked direction
- Premium Animated Adventure visual identity
- Animated Fantasy Adventure character style
- Hybrid hero creator: manual core, optional AI/photo refinement
- Hybrid world: illustrated overworld + richer local diorama/story-map regions
- Adaptive AI GM + recurring ensemble
- Three traveling companions plus 2–3 home-base specialists
- The Wayfarers: Kaia, Milo, Seren
- Growing skyship home base
- Hybrid Relic Adventurer ship
- Layered Hybrid silhouette
- Hybrid Awakening propulsion
- Layered Home interior with Relic Restoration progression
- Hybrid Cinematic HUD
- Hybrid Cinematic Party Combat
- Hybrid Treasure System; rare items follow Meaningful Relic philosophy
- Hybrid reward reveals
- Hybrid Adaptive Score: fantasy orchestra + modern pulse
- Hybrid onboarding prologue centered on Ship Awakening
- Opening: Silent Drift -> Darkened Heart -> First Spark -> world reveal
- Adaptive First Spark micro-quest
- Layered Crystal Heart cinematic payoff
- First region: Amber Highlands that reveal stranger floating/luminous layers
- Intro enemies: Driftlings -> Hesitation Wraith
- Hybrid Campaign Model: one primary arc + 1–2 side arcs
- Hybrid Reality Lens
- Hybrid Adaptive AI autonomy
- Hybrid Consequence Model
- Hybrid Identity character progression
- Hybrid Relationship System
- Hybrid Daily Opening
- Hybrid Evening Ritual
- Captain's Log: Hybrid Living Chronicle

## Product-owner rule
Routine design and implementation decisions are delegated. Only stop for a genuine fork in the road: decisions that materially alter core gameplay, platform architecture, monetization, major AI behavior, art direction, privacy, social/multiplayer model, or another hard-to-reverse product choice.
