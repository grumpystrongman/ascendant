# Ascendant — The Real-Life RPG

Ascendant turns real-life goals into a living animated-fantasy RPG campaign.

## Current vertical slice

- Cross-device PWA shell
- Silent Drift / First Spark campaign concept
- Adaptive daily quests
- Quest completion -> combat damage -> XP / coins / ship progress
- The Wayfarers: Kaia, Milo, and Seren
- Amber Highlands world presentation
- Growing relic skyship
- Hero stats, skills, relic inventory
- AI Game Master local simulation
- Reality Lens
- Mini-games
- Captain's Log
- Local persistence and save import/export

## Development

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```
